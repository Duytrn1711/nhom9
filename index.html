Mục tiêu Phát triển

Xây dựng một nền tảng thương mại điện tử "Zero-Library" nhằm tối ưu hóa tối đa hiệu suất tải trang.

  • Tốc độ: Thời gian phản hồi dưới 500ms.
  • Tương thích: Chạy tốt trên cả IE Edge cũ và Chrome mới.
  • UX: Quy trình thanh toán đơn giản hóa 3 bước.

Đặc biệt chú trọng vào khả năng bảo trì và mở rộng của mã nguồn thông qua việc áp dụng chuẩn ES6+.

Công nghệ lõi

Chúng tôi không sử dụng các Framework nặng nề để đảm bảo tính nhẹ nhàng của hệ thống.

Semantic HTML

Sử dụng các thẻ chuẩn giúp SEO và các trình đọc màn hình hoạt động tốt hơn.

Modern CSS

Flexbox & Grid Layout kết hợp với biến CSS giúp quản lý giao diện tập trung.

Vanilla JS

Xử lý Logic, Giỏ hàng và Tìm kiếm hoàn toàn bằng JavaScript thuần.

Phân tích Header & Navigation

Header được thiết kế dạng Sticky giúp người dùng truy cập giỏ hàng mọi lúc.

  • Tìm kiếm thời gian thực.
  • Badge số lượng cập nhật động.
  • Menu điều hướng phân cấp rõ ràng.

Tìm kiếm Tức thì (Live Search)

Sử dụng sự kiện input để lọc danh sách sản phẩm ngay khi người dùng gõ phím.

searchInput.addEventListener('input', (e) => { const value = e.target.value.toLowerCase().trim(); // Lọc mảng sản phẩm ngay tại trình duyệt const filtered = products.filter(p => p.name.toLowerCase().includes(value) ); renderResults(filtered); });

Kết quả được hiển thị trong một Dropdown tùy chỉnh, giúp tăng tỷ lệ chuyển đổi mua sắm.

Giỏ hàng & LocalStorage

Hệ thống giỏ hàng được đồng bộ hóa với bộ nhớ trình duyệt, tránh mất dữ liệu khi F5.

  • Thêm sản phẩm không load lại trang.
  • Tự động lưu vào localStorage.
  • Xóa sản phẩm với xác nhận an toàn.

Giải pháp Thanh toán VietQR

Tự động sinh mã QR dựa trên tổng tiền giỏ hàng, mang lại sự tiện lợi tối đa.

  • API sinh mã chuẩn VietQR.
  • Nội dung chuyển khoản định danh.
  • Bảo mật, không lộ thông tin thẻ.
